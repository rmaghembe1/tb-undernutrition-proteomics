# Public release boundary

This repository is an intentionally sanitized computational companion.

## Included

The public package contains:

- aggregate module-level statistical summaries;
- aggregate serum nutritional-metabolic recovery-axis results;
- recovery-axis protein/module membership and loadings;
- publication-facing figures;
- generic input-data templates;
- reproducibility and provenance documentation.

## Excluded

The public package does not contain:

- collaborator-supplied processed abundance matrices;
- participant-level clinical metadata;
- sample or participant linkage files;
- TMT sample-mapping files;
- participant-level molecular scores;
- participant-level longitudinal deltas;
- private analysis-ready matrices;
- collaborator correspondence;
- co-author review documents;
- manuscript working files;
- copyrighted full-text literature collections.

Four portable publication-facing analysis scripts are included. Earlier collaborator-coupled development scripts remain excluded.

The underlying source-study mass-spectrometry data are associated with
ProteomeXchange/PRIDE accession PXD040546 and MassIVE accession MSV000091392.
