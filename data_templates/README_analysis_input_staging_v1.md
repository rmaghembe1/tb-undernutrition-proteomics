# Serum Proteomics Source Data Staging Area v1

Generated: 2026-07-07

Place real analysis inputs in the appropriate folders below:

- `proteomics_matrix/`: serum-proteomics abundance matrix or long-format abundance table.
- `clinical_metadata/`: participant/sample metadata with BMI and time point.
- `protein_annotation/`: UniProt/gene/protein annotation table if available.
- `batch_run_metadata/`: batch, run, plate, TMT plex or acquisition metadata if available.
- `outcome_metadata/`: optional culture conversion, cure, relapse, treatment failure or adverse-event data.
- `data_use_notes/`: notes about source, permissions and redistribution boundaries.

Important: participant-level data should remain local/private unless explicit permission or public-data terms allow redistribution.
