# Public analysis resources

`curated_legacy_module_mapping.tsv` is a participant-independent
module-to-protein mapping used by the public v0.8.2.2 workflow.

It contains only:

- module identifiers;
- module labels;
- protein feature identifiers;
- protein mnemonics;
- curated gene symbols.

It contains no participant identifiers, sample identifiers, clinical
measurements, treatment assignments, longitudinal observations, or
collaborator-supplied abundance values.

The public resource is derived from the locked analytical workflow and is
included so that the selected legacy modules can be reconstructed without
accessing the private research workspace.
