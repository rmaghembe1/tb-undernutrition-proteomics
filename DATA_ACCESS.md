# Data access

The analyses reported in this repository were performed using processed longitudinal serum-proteomics abundance data and linked clinical and TMT sample-mapping files supplied by collaborators from the Jacobs/Powell study.

The corresponding source-study mass-spectrometry data are publicly deposited under:

- ProteomeXchange/PRIDE accession **PXD040546**
- MassIVE accession **MSV000091392**

The collaborator-supplied processed files used for the present secondary analysis are not redistributed here.

Accordingly, this repository does not contain:

- participant-level clinical metadata;
- participant or sample identifiers;
- TMT sample-linkage files;
- collaborator-supplied processed abundance matrices;
- reconstructed participant-level proteomics matrices;
- participant-level molecular scores or deltas.

Only aggregate statistical outputs, protein/module membership information, publication figures, and generic input templates are included.

Researchers seeking to reproduce the analysis with participant-level source material must obtain the relevant data through the appropriate public repository and/or data custodians and comply with the applicable data-use conditions.
